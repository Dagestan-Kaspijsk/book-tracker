# Book Tracker

Автор: Хаджаева Малика Ильясовна

## Описание программы

Это графическое приложение для учёта прочитанных книг. Позволяет добавлять новые книги, фильтровать их по жанру и количеству страниц, а также сохранять и загружать список из файла формата JSON.

Приложение написано на языке Python с использованием библиотеки Tkinter для создания графического интерфейса.

## Инструкция по запуску

1.  Убедитесь, что у вас установлен Python 3.8 или новее.
2.  Скачайте или склонируйте этот репозиторий.
3.  Откройте папку проекта в терминале (командной строке).
4.  Запустите приложение командой:
    ```bash
    python main.py
    ```

## Функционал

-   **Добавление книг:** Введите название, автора, жанр и количество страниц, затем нажмите кнопку "Добавить книгу".
-   **Сохранение в JSON:** Нажмите кнопку "💾 Сохранить в JSON", чтобы сохранить текущий список книг в файл `books.json`.
-   **Загрузка из JSON:** Нажмите кнопку "📂 Загрузить из JSON", чтобы загрузить данные из файла.
-   **Фильтрация:** Используйте выпадающий список для фильтрации по жанру или введите количество страниц, чтобы найти книги, которые длиннее указанного значения.

## Примеры использования

1.  Добавьте 3 книги с разными жанрами.
2.  Сохраните их в JSON.
3.  Очистите список (можно загрузить пустой файл или просто добавить новые книги).
4.  Загрузите данные обратно — книги вернутся.
5.  Выберите жанр "Фантастика" в фильтре — в списке останутся только книги этого жанра.
